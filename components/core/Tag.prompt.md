# Tag

Small technical chip for stacks, tools, and topics. The portfolio uses dense rows of these under every project and experience entry.

```jsx
<Tag>vLLM</Tag>
<Tag tone="accent">GRPO</Tag>
<Tag tone="cobalt">W4A16</Tag>
<Tag tone="solid">★ featured</Tag>
```

Tones: `neutral` (default, raised paper), `accent` (clay wash), `cobalt` (blue wash), `solid` (ink), `outline`. Mono typeface by default — set `mono={false}` for sentence-case labels. Lay out in a flex row with `gap: 6px`.
