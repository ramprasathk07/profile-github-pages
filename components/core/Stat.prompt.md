# Stat

A large serif figure with a mono label. For headline metrics — "2+ years", "#1 hackathon", "85% reasoning".

```jsx
<Stat value="2+" label="years in production AI" />
<Stat value="#1" label="Mistral AI Hackathon '26" accent />
```

Set `accent` to render the figure in clay. Group several in a flex row with generous gaps.
