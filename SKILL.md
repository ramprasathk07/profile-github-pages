If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.

Core of the brand: warm-paper editorial minimalism. Monochrome ink-on-paper with a single terracotta (`--clay #BB4A2C`) signal. Newsreader serif for display + long-form, Hanken Grotesk for UI, JetBrains Mono for labels/code. Hairlines over shadows, small radii, quiet quick animation, `// section` mono markers, `~/` prompt wordmark. First-person, plain-spoken, numbers-forward copy; emoji only as project/award glyphs.

If the user invokes this skill without any other guidance, ask them what they want to build or design, ask a few questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.
